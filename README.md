## 01 / The person behind the code

I'm Niraj, a software engineer who likes to understand what happens beneath the abstraction—and then build something useful with it.

My work spans AI applications, backend development, and data engineering. I'm especially interested in the engineering around language models: how they retrieve the right information, use external tools, carry context across tasks, and produce answers we can evaluate.

I've worked on ETL pipelines, time-series forecasting, and internal analytics tools. Across those projects, I enjoy the same challenge: turning messy inputs and practical requirements into software people can use.

🎓 B.S. in Computer Science · Southeastern Louisiana University

> I like the moment when a system stops feeling like magic and starts making sense.
