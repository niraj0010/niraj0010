# Install your profile README

1. Open your public profile repository (the repository whose name matches your GitHub username).
2. Replace its root README.md with the README.md in this folder.
3. Upload the assets folder alongside it, preserving the filenames.
4. Commit the changes and open your GitHub profile.

The banner is a bundled animated GIF. No third-party image service, API key, or scheduled workflow is required. Its words remain still; only the small network particles move.

For a motion-free version, change assets/header.gif to assets/header-static.png in README.md. The GIF itself cannot adapt to a visitor's reduced-motion setting.

The section links follow GitHub's generated heading anchors. The design uses native Markdown, basic HTML, and a local image. Review the final rendering on GitHub after uploading; it has not been tested inside your account.

Optional next step: add your actual project repository and contact links. None have been guessed or inserted.

GitHub setup reference: https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme
